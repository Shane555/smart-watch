# Design decisions

One short record per significant decision, numbered in order: `0001-short-title.md`, `0002-…`.
Copy [the template](0000-template.md) to start a new one.

A decision record is never edited after it's accepted. If a later decision changes it, write a new
record and mark the old one "Superseded by 00NN".
