# Rust Smart Watch

Design documentation for a wrist-worn smart watch: ESP32-C3, custom PCB, 3D-printed enclosure,
firmware in Rust.

These docs follow the project in the order the work happens: requirements first, then
architecture and the power budget, then the decisions that come out of them, and finally
bring-up, testing and errata for each hardware revision.

The source files live in the [`docs/` folder of the repo](https://github.com/Shane555/smart-watch/tree/HEAD/docs).
